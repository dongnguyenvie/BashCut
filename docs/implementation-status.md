# Implementation status

M0 foundations and partial M1/M2 features are implemented. This is not completion of M0 acceptance or M1–M6. The roadmap remains the full requested scope, including Claude/Codex terminals and model API script generation.

## Implemented

- Separate Git repository, ignore rules, SwiftPM/XcodeGen configuration, dependency lockfiles and verification scripts.
- Lossless schema-v1 JSON, rational FPS, seven role-based tracks, atomic EditOperation batches, source/overlap/render validation, revisions and persisted undo/redo.
- New Project wizard with name, aspect ratio, resolution, rational FPS, content language, style, destination and optional footage symlink; exclusive publication preserves existing folders and the current document on failure.
- Legacy `edl.json` import maps cuts, source ranges, record frames, borrowed picture, linked dialogue, transforms, tags, split subtitles, voiceovers and section markers, writes a new project without touching legacy files, and shows a cut/voiceover/duration comparison report with unsupported-area warnings.
- Modular OpenTimelineIO export preserves source/timeline rates, gaps, overlapping layers, text generators, speed effects, section markers and BashCut metadata. It is available from the Export sheet and through the token-gated, in-app-approved CLI.
- Stable, undoable transitions support dissolve, whip, blink, zoom, spin, shutter and wipe from the Transitions panel and agent wire format. Preview and export share the same frame tweening; invalid transitions are removed when edits separate their clips.
- Project-scoped `.cube` 3D LUTs have a validated catalog, undoable add/delete/apply operations, adjustable clip strength and agent wire operations. The shared Core Image renderer honors LUT domains in preview and export; LUT files stay on disk when their catalog entry is undone or restored.
- The Viewer can show a synchronized vertical Before/After split. Its ephemeral Before composition bypasses color adjustments and LUTs while preserving timing, transforms, text, transitions and stored project data.
- Mockup-based native layout: eight library tabs, media thumbnails/search, viewer with safe area, five Inspector tabs, scroll/zoom/snap timeline, drag move/trim, history and structural review.
- Atomic Roll/Slip via Inspector, modifier-key timeline gestures and agent commands; Shift-Delete lifts without ripple. Core/wire tests cover bounds, mixed FPS and undo/redo; modifier-key gestures still need native UI verification.
- SRT add/replace/export from the Text library and authenticated CLI, Unicode/multiline support, rational-FPS conversion and atomic undo. Native file-picker smoke verification for these new controls remains outstanding.
- Cached stereo waveforms on Main/audio tracks, read off the UI actor with cancellation and bounded peak data. Source changes invalidate cache on refresh; waveform refresh/progress/errors appear in the timeline toolbar. Native visual verification remains outstanding.
- Original-media imports, source preview with In/Out and insert/overwrite, split/delete, tags, transform/opacity, text editing and six shared Core Text presets (Bold Outline, Cinematic Serif, Keyword Sticker, Place Card, Hook Title and Chapter Card), emoji text stickers, color adjustments, volume/mute/fades and constant speed.
- Automatic Change Framing cycles deterministic Wide, Medium, Close and left/right emphasis presets through validated `transform` plus `reframePreset` properties. Manual transform edits switch the item back to Custom; agents use the same `setProperties` schema.
- Media thumbnails support debounced, quantized hover-scrubbing with source time feedback. Freeze Frame holds the source frame under the playhead across the clip duration in both preview and export.
- `@assets/...` media resolves through the configured workspace in thumbnails, source viewing, plugin inputs, preview and export. Validation rejects unsupported namespaces and traversal outside the shared assets directory.
- Video media with embedded sound creates reciprocal Main/Dialogue items. Linked pairs move, trim, split, slip, roll and delete together in one undo step; the Inspector can unlink them and agents can assign or remove a link.
- Dragging a clip within a magnetic track reorders and compacts that track; linked Dialogue items follow the new Main positions. Agents can invoke the same deterministic reorder operation.
- AVFoundation custom compositor shared by preview/export, Vietnamese captions and audio mix. Export has TikTok, YouTube 1080p/4K, Quick Draft and ProRes presets, AAC 320 kbps, background progress/cancel, optional companion SRT, receipts and CLI status; failed/cancelled video output is cleaned up. The last 20 reports persist per project and compare duration, file size, cuts, captions, tagged speech coverage and LUFS with the previous export. An optional `audio.loudness` provider enables two-pass target-LUFS normalization with a −1 dBTP ceiling, final verification and undoable mix-gain/provenance persistence.
- Atomic save, 30-second/deactivation autosave, recovery choice, restored history and external-file conflict/reload handling with a project/media/track/item differences sheet.
- Project directories use filesystem event monitoring for external-change checks, with an activation check as a fallback; the editor no longer rereads the project file every second.
- Real SwiftTerm Claude/Codex/Shell tabs, workspace/resume input, context/quick-action paste, current-frame attachment, a detachable resizable Agent window, token-scoped local automation socket, bundled CLI and official-SDK `bashcut-mcp`, edit-author badges and metadata audit log. Frame attachments are bounded PNGs passed by local path to terminals and through native multimodal payloads to Responses, compatible Chat Completions and Anthropic APIs. Claude and Codex receive ephemeral stdio MCP configuration for the same 22 socket-backed commands. Agent exports require a live token plus an in-app approval sheet showing the concrete output before rendering.
- Claude and Codex resume bookmarks persist separately per canonical project outside source control. Bounded background discovery reads local session metadata to offer matching existing sessions and records newly launched session IDs automatically. Handoff opens or selects the other provider and transfers current project, timeline, memo and skill context.
- Dynamic schema-v2 tracks support repeated video/image, text and audio layers, explicit stacking order and vertical timeline scrolling. The compositor interleaves text/video by track order and reuses assets/composition lanes.
- Agent edits retain a before/after item diff, show ◆ markers and an Undo/Show Changes toast, and restore the latest agent diff from history after reopen.
- Agent Knowledge manages a shared project memo and project skills surfaced to both `.claude/skills` and `.agents/skills`.
- A versioned out-of-process plugin manifest/catalog and Plugins installer UI keep optional dependencies out of the base app, show exact install commands before approval and report dependency health. The process runner uses one bounded request per child process and a filtered environment.
- `CapabilityService` (`BashCut/Core/Plugins`) is the single path from a capability request to a validated, provenance-tagged result. The Voice, Text and Audio panels, normalized export and automation all use it. Authenticated `captions.generate`, `beats.detect` and `voice.speak` commands (CLI and MCP) run as background jobs with `jobs.status`/`jobs.cancel` and apply one undoable agent-attributed edit; `plugins.list` reports providers, preferences and diagnostics.
- The Voice panel resolves a healthy `voice.synthesize` provider, supports an undoable project preference, and generates three confined, validated takes. Providers may return scored take arrays; legacy single-output providers remain compatible. The UI previews, scores, selects and inserts one take with plugin provenance and cleans discarded request folders.
- Direct voiceover recording requests macOS microphone permission, writes 48 kHz mono PCM WAV files under the project, shows duration/input level and inserts validated audio at the playhead with undoable media provenance.
- Auto Captions resolves a healthy `captions.transcribe` provider, sends an explicit media path and language, validates bounded UTF-8 SRT output and imports it atomically with provider provenance.
- The Audio panel resolves `audio.beats`, validates BPM and strictly increasing source times, maps beats through clip trim/speed to integer timeline frames, and adds undoable beat-grid drawing and snapping.
- Music tracks support undoable automatic ducking under tagged Dialogue and all Voiceover regions. The Inspector exposes level, attack and release in integer frames; the shared AVFoundation mix combines ducking with clip gain and fades for preview and export.
- Settings persist workspace, default Claude/Codex agent, agent edit permission, export preset and interface language. Disabling edit permission immediately revokes live Claude/Codex tokens; re-enabling requires a fresh session.
- Doctor reports workspace access, Claude/Codex and optional tool discovery, automation socket status, agent instructions/skills, project folders, plugin catalog diagnostics and live dependency health.
- OpenAI Responses/compatible Chat Completions/Anthropic Messages adapters, Keychain credentials, editable generated scripts with explicit run, and revision-checked API timeline proposals. Details in [automation.md](automation.md).
- English/Vietnamese resources for current controls, RenderEngine and model-transport protocol boundaries. Core editing invariants stay outside providers; plugins are executable bundles rather than in-process dynamic libraries.

## Remaining acceptance / limitations

- The regenerated Xcode project builds with signing disabled and package-plugin validation skipped for the locked SwiftTerm build plugin. Full UI automation coverage and real authenticated Claude/API tasks are not verified.
- Real DJI playback/scrub/export performance acceptance remains separate from synthetic tests. Do not infer it from the synthetic fixture.
- M1: broader accessibility QA.
- M2: full command/UI parity beyond the current 22 MCP/CLI commands and voice-enrollment approval. Analysis and interchange plugin providers still need wiring to their feature panels. Provider-backed automation jobs are not yet smoke-tested natively with a real agent and installed provider.
- Plugin platform: bundled native loudness/beat providers, API version window and availability states, long-lived session mode, hash-pinned trust and declared provider options are planned (spec `03-architecture.md` §5).
- M3–M6: bundled transcription/beat/loudness providers and real-engine acceptance, multi-job export queue, expanded legacy effect/overlay/SFX import, voice cloning, richer effects/speed ramps and additional interchange validation. Resolve remains reserved by the spec.
- Review and export coverage use explicit speech tags plus voiceover timing; they do not measure actual silence or transcribe untagged audio. Export loudness is measured only when an installed provider is selected for normalization. Transitions/Voice tabs identify their unimplemented portions.
- Ripple affects the edited track and a linked A/V counterpart when present; unrelated tracks do not ripple. Source insert/overwrite targets Main and creates linked Dialogue sound for media with audio. Unknown future effects round-trip but are not rendered.
- Full-snapshot undo has memory cost. history.jsonl stores one atomic history checkpoint; append-only journal/compaction is pending.
- Some dynamic diagnostic messages remain English; language override and complete localization QA are pending.
- Direct recording builds and validates through the normal import path, but live microphone permission/meter capture still needs native hardware smoke verification.
